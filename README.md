# Система управления авиакомпанией

Flutter-приложение для управления рейсами, самолётами, пилотами, услугами и
пассажирами. Интерфейс поддерживает поиск, фильтрацию, сортировку, пагинацию,
валидацию форм и безопасное удаление записей.

## Сущности и связи

- рейс связан с одним самолётом;
- рейс связан со многими пилотами и услугами;
- пассажир содержит один вложенный билет;
- выбор самолёта ограничивает список пилотов по квалификации.

Полный CRUD реализован для рейсов, самолётов, пилотов, услуг и пассажиров.
Данные сохраняются локально в `shared_preferences` под версионированным ключом
`airline_v2`.

## Запуск

    flutter pub get
    flutter run -d chrome

## Проверка

    flutter analyze
    flutter test
    flutter build web

Если стандартная web-сборка Windows не работает из каталога с кириллицей,
проект можно временно скопировать в путь без кириллицы и выполнить сборку там.
